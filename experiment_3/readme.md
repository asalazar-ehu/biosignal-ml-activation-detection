# Instructions for experiment 3
Experiment 3 is split into two parts. The first one corresponds to the deep learning benchmarking and the second corresponds to the training of the hybrid MST-Conformer architecture. Each of these parts has its own python notebook.

Besides, both python notebook require using the two files related to experiment 3: "All_ECR_9.csv" and "PER_SUBEJCT_WESAD_raw_signals_norm_allSubjects.mat". These two files can be found in Zenodo repository for this work (doi: 10.5281/zenodo.23337725).

Please note that even if the deep learning benchmark part does not use any features extracted from the physiological signals (which are in "All_ECR_9.csv") the file containing those features is the one containing the classification label for each instance and so, it is also needed for running that part of the experiment.
