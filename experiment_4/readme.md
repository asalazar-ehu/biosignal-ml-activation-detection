# Instructions for experiment 4 
Experiment 4 is split into two parts. The first one corresponds to the training the traditional ML algorithms and the second corresponds to the training of the hybrid MST-Conformer architecture. Whereas the first is run in Matlab, the second is included in a python notebook ready to be run in Google Colab.

Both parts of require using the "All_ECR_27.csv" file. Besides, the part of experiment 4 related to the MST-Conformer also requires using "PER_SUBEJCT_WESAD_raw_signals_norm_allSubjects.mat". These two files can be found in Zenodo repository for this work (doi: 10.5281/zenodo.23337725).
